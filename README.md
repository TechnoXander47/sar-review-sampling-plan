# SAR Review Sampling Plan

How to pick which SARs to review each month so the sample is useful and not just convenient.

## Principles

1. **Mix it up.** Sample across alert types, outcomes and analysts, not only the latest filings.
2. **Include awkward cases.** Add at least one complex or high-value report to every sample.
3. **Keep it small and regular.** A modest sample every month beats a large one every year.
4. **Rotate focus.** Pick one theme a month: glossary codes, specificity, linked cases.
5. **Record why each item was chosen.** That keeps the sample honest.

## Steps

1. List the month's submitted reports by alert type.
2. Choose several types and pick one or two reports from each.
3. Add one report that someone found difficult to write.
4. Review against your checklist.
5. Log results in `sampling-log.csv`.

## Reading the results

- A single month shows direction, not proof.
- Repeated gaps across months point to process issues.
- If gaps cluster around missing information, treat them as a systems backlog, not training.

## Caution

Do not set pass-rate targets before you have several months of baseline data.
